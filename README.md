# Shift career dashboard

A responsive dashboard replica built with plain HTML, CSS, and JavaScript. No build step, package installation, or server is required.

## Run locally

1. Open this folder in VS Code.
2. Open `index.html` in a browser (or use the VS Code Live Server extension if you prefer a local server).

Keep the `assets` folder beside `index.html`; it contains the supplied light- and dark-mode logos.

## Customize

- Edit the theme colors in the `:root` and `[data-theme="dark"]` sections near the top of `index.html`.
- Update the sample applications, events, learning resources, Qatar-market tool counts, opportunities, and mock assessments in the JavaScript data arrays.
- Change the landing name, education, and skills in the `profile` object.
- The navigation, theme switch, application form, profile/CV dialogs, saved opportunities, learning filters, skill-path selector, mock assessment practice, and Shift AI chat preview are interactive.
- Qatar job-market counts and example experience/opportunities are fictional demo data. The chat is a local preview; no live job-posting search, APIs, AI service, file upload, or account storage is connected. Most changes last only for the current page session; the light/dark preference is saved in browser storage.
